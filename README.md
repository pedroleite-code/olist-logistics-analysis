# Olist Logistics Analysis

Analysis of delivery performance in Brazilian e-commerce: where and why orders are late, and what that means for customer satisfaction and freight cost.

> Work in progress.

## Data

Brazilian E-Commerce Public Dataset by Olist, published on Kaggle (olistbr/brazilian-ecommerce).

- Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- License: CC BY-NC-SA 4.0 (non-commercial use, attribution required)
- The raw data is not included in this repository. See the download instructions below.

## How to get the raw data

1. Download the dataset from the Kaggle link above (a free Kaggle account is required).
2. Extract the CSV files into data/raw/.
